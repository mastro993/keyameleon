## What these plans decided

- The menu-bar panel gets one notice and at most one button (Request Permission or Retry Now). The footer stays Pause or Resume, Settings, and Quit. Keyboard Assignment editing stays in Settings.
- Paused is the one Switching Status with no notice block. It rides on the panel title as `(paused)`, because one word is enough and the Resume action is already in the footer.
- Early selection on disconnect is not adopted. The setup sentence describes the current limit instead.
- Virtual HID, keyboard seizure, and a First-Key Guarantee stay out of scope.

## Findings considered and rejected

- Homebrew cask: the V1 spec puts it out of scope, after an earlier release note sketched a tap. Not worth reopening here.
- Virtual HID, seizure, and a seize-switch-forward prototype: named as parked V2 research and kept outside the monitor-only boundary.
- Per-app Keyboard Assignments, cloud sync, Mac App Store, Intel Macs, and stateful input methods: V1 out of scope. Eligible Input Sources stay enabled keyboard layouts.
- In-app log viewer: the 2026-09-22 logging choice is a file under `~/Library/Logs/Keyameleon` and an Open button on About.
- macOS 15 support: ADR 0001 moved the Supported Release to macOS 26.
- README panel screenshot: deferred on purpose and still missing. Left unplanned in this batch; take it after the panel notice exists so the shot matches the product.
